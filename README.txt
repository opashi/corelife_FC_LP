Core Life FC用LP

■ 起動方法
index.html をブラウザで開いてください。サーバーは不要です。

■ ファイル構成
- index.html : ページ構造・テキスト
- css/style.css : デザイン・レスポンシブ
- js/script.js : スクロール演出・ページ内リンク
- images/ : 仮画像・仮ロゴ

■ 画像差し替え
images フォルダ内のSVGを、実際の写真・ロゴに置き換えてください。
HTML内の画像ファイル名（src）を変更することもできます。
推奨画像比率：
- hero-training-placeholder.svg：横長 4:3〜16:9
- problem / reason系：横長 4:3
- logo-placeholder.svg：横長ロゴ

■ 公開前に確認・差し替えが必要な箇所
1. 体験申込・資料請求・受講相談のリンク先（現在は仮のmailto）
2. Google Mapの埋め込みコード
3. MGAロゴ、人物・授業・施術写真、研究資料
4. コース名・実績数値・掲載情報などの最新内容
5. プライバシーポリシーのURL

※元LPの縦長画像で確認できた内容をもとに、テキスト・表・装飾をHTML/CSSで再構成した初稿です。
元ページ内の画像に焼き込まれている細かな文章や、表示環境による差異は完全一致を保証するものではありません。
